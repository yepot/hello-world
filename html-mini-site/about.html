About the project

Learning by making.

Bright Start is a mini website created to practice the foundations of HTML. Building a real page turns individual tags into something useful, visual, and easy to share.

What I practiced

  • Organizing a page with semantic elements
  • Linking two HTML documents together
  • Adding an image with helpful alternative text
  • Creating a responsive layout with CSS

This project is simple by design, but it is also a starting point for more creative websites in the future.
